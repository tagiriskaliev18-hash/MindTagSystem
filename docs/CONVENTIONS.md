# Правила экосистемы MindTagSystem

Эти правила для людей и ИИ-агентов (Claude Code, Antigravity и других), которые работают с любым проектом экосистемы.

## Каждый проект знает об экосистеме

В конце README каждого проекта есть раздел **«🌐 Часть экосистемы MindTagSystem»**. В нём:

- что проект входит в MindTagSystem и ссылка на этот репозиторий;
- автор — Тагир Искалиев ([@tagiriskaliev18-hash](https://github.com/tagiriskaliev18-hash));
- роль проекта в экосистеме;
- таблица всех проектов экосистемы с одной строкой о каждом.

Источник правды — [`ecosystem.json`](../ecosystem.json). Когда что-то меняется, сначала правится он, затем таблицы в README.

## Шаблон раздела

```markdown
## 🌐 Часть экосистемы MindTagSystem

<Название> входит в **[MindTagSystem](https://github.com/tagiriskaliev18-hash/MindTagSystem)** — экосистему для программистов, которую создаёт **Тагир Искалиев** ([@tagiriskaliev18-hash](https://github.com/tagiriskaliev18-hash)): своя ОС, браузер, IDE, ИИ-ядро и приложения, которые работают вместе на любом устройстве.

**Роль в экосистеме:** <одна строка>.

| Проект | Что делает |
|---|---|
| ... | ... |

Как всё связано: [архитектура MindTagSystem](https://github.com/tagiriskaliev18-hash/MindTagSystem/blob/main/docs/ARCHITECTURE.md).
```

## Как добавить новый проект

1. Добавьте запись в `ecosystem.json`: `id`, `name`, `repo`, `layer`, `role`, `summary`, `stack`, `status`.
2. Добавьте строку в таблицу в `README.md` этого репозитория и раздел в `docs/PROJECTS.md`.
3. Добавьте раздел «Часть экосистемы MindTagSystem» в README нового проекта.
4. Добавьте строку о новом проекте в таблицы README остальных проектов.
5. Добавьте на GitHub тему (topic) `mindtagsystem` в настройках репозитория, чтобы проекты находились поиском `topic:mindtagsystem`.

## Общие технические правила

- **Секреты не хранятся в коде.** Ключи API только в переменных окружения или `.env`, который в `.gitignore`. В репозитории лежит `.env.example`.
- **ИИ через OpenAI-совместимый интерфейс.** Проект обращается к модели по адресу из настроек, чтобы его можно было переключить на шлюз AI Duo или локальную модель.
- **Работа без ключей.** Если ключа нет, проект продолжает работать в урезанном режиме и честно об этом говорит.
- **Русский язык** в интерфейсах и документации, если проект не рассчитан на другую аудиторию.
